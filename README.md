# Lemon Luxury Hotel Booking Website

## Overview
Lemon is a modern luxury hotel booking website developed using HTML, CSS, JavaScript, and Three.js. The project provides an interactive and visually rich hotel reservation experience with elegant UI design and dynamic frontend features.

## Features
- Responsive hotel booking interface
- Interactive room and suite listings
- AI-powered concierge chat interface
- Dynamic booking modal and pricing system
- 3D animated hero section using Three.js
- Smooth scrolling and modern animations
- Mobile-friendly responsive design
- Luxury-inspired UI/UX design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Three.js

## Functionalities

### Hotel Booking System
- Room browsing
- Reservation modal
- Dynamic price calculation
- Guest selection
- Booking confirmation system

### AI Concierge
- Interactive concierge chat interface
- Personalized guest assistance simulation
- Smart hotel recommendation responses

### UI/UX Features
- Animated loading screen
- Responsive navigation menu
- Interactive notifications
- Hover effects and transitions
- Smooth animations and scrolling
